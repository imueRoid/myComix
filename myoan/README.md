# 법률사무소 묘안 홈페이지

한 페이지로 된 사무소 홈페이지와 개인정보 처리방침 페이지입니다. 별도 프로그램이나 서버 설정 없이, 이 폴더를 웹호스팅에 그대로 올리면 동작합니다.

## 구성

```
myoan/
├── index.html            홈페이지 (사무소 소개, 업무분야, 변호사 소개, 진행 절차, 상담 안내, 오시는 길)
├── privacy.html          개인정보 처리방침
└── assets/
    ├── css/style.css     디자인 (색·글꼴은 맨 위 :root 변수에서 바꿉니다)
    ├── js/main.js        메뉴, 상담 신청 양식 등 화면 동작
    └── img/              인장 로고, 파비콘, 링크 미리보기 이미지(og-image.png)
```

미리 보려면 `index.html`을 브라우저로 열면 됩니다. 실제 서버와 같은 환경에서 보려면 이 폴더에서 `python3 -m http.server`를 실행한 뒤 `http://localhost:8000`에 접속합니다.

## 공개 전에 바꿔야 할 곳

아래 자리표시자는 모두 `index.html`, `privacy.html`에 들어 있습니다. 편집기의 “모두 바꾸기”로 한 번에 바꾸면 됩니다.

| 자리표시자 | 바꿀 내용 | 들어 있는 곳 |
|---|---|---|
| `○○○` | 대표변호사 성명 (광고책임변호사·개인정보 보호책임자 포함) | 변호사 소개, 바닥글, 처리방침 제10조 |
| `02-000-0000` | 대표 전화번호 | 첫 화면 버튼, 상담 안내, 하단 버튼, 바닥글 |
| `02-000-0001` | 팩스 번호 | 바닥글 |
| `contact@example.com` | 상담 메일을 받을 이메일 주소 | 상담 안내, 신청 양식(`data-mailto`, `action`), 바닥글 |
| `000-00-00000` | 사업자등록번호 | 바닥글 |
| `서울특별시 ○○구 ○○로 00, ○○빌딩 0층` | 사무소 주소 | 오시는 길, 바닥글, 검색엔진용 정보 |
| `https://www.example.com/` | 홈페이지 주소(도메인) | `index.html` 머리 부분(canonical, og:url, og:image) |

그 밖에 직접 고쳐 쓸 부분:

- **변호사 소개**의 학력·자격·경력(`○○대학교` 등)
- **오시는 길**의 지하철·버스·주차 안내
- **상담 시간**(평일 오전 9시 – 오후 6시로 적어 두었습니다)
- **업무분야** 6개 항목 — 실제로 맡는 분야에 맞게 빼거나 더합니다
- **개인정보 처리방침** 시행일(제12조), 보유 기간(제3조) — 사무소 방침에 맞게 확정합니다

주소를 바꾸면 “네이버 지도에서 보기”, “카카오맵에서 보기” 버튼이 그 주소로 자동 연결됩니다.

## 변호사 사진 넣기

`assets/img/profile.jpg` 파일을 넣으면 변호사 소개에 자동으로 표시됩니다. 세로 4:5 비율(예: 800×1000px)을 권장합니다. 사진이 없으면 큰 화면에서는 인장 그림이 대신 보이고, 휴대폰에서는 빈 칸이 숨겨집니다.

## 상담 신청 양식

“메일로 상담 신청하기”를 누르면 방문자의 메일 앱이 열리고, 입력한 내용과 동의 일시가 담긴 메일이 `contact@example.com` 앞으로 작성됩니다. 방문자가 메일을 보내야 접수됩니다. 서버나 외부 서비스를 거치지 않으므로 상담 내용이 제3자에게 넘어가지 않습니다.

메일 앱이 없는 PC를 위해 “신청 내용 복사하기” 버튼도 함께 나타납니다. 메일 앱 없이 바로 접수되게 하려면 서버 접수 기능(PHP 등)이나 양식 접수 서비스를 따로 연결해야 하며, 이 경우 개인정보 처리방침의 위탁 조항(제5조)도 함께 고쳐야 합니다.

## 인터넷에 공개하기

- **일반 웹호스팅**: `myoan` 폴더 안의 파일을 호스팅의 웹 루트(`public_html` 등)에 올립니다.
- **GitHub Pages**: 이 폴더 내용을 공개 저장소에 올리고 Settings → Pages에서 배포합니다.

공개한 뒤에는 `og-image.png` 주소가 실제 도메인으로 바뀌어 있어야 카카오톡 등에서 링크 미리보기가 제대로 나옵니다.

## 광고 규정 관련해 반영한 점

변호사법 제23조와 대한변호사협회 「변호사 광고에 관한 규정」을 고려해 다음을 지켰습니다. 문구를 고치실 때도 같은 기준을 유지하시기 바랍니다.

- ‘최고’, ‘유일’, ‘전문’(전문분야 등록 없이), 승소율·성공률 같은 수치, 결과를 보장하는 표현을 쓰지 않았습니다.
- 바닥글에 광고책임변호사 성명을 적는 자리를 두었습니다.
- 다른 변호사나 사무소와 비교하는 표현을 쓰지 않았습니다.
- 소개 문구(“변호사가 직접 작성합니다” 등)는 실제 업무 방식과 맞는지 확인해 주세요. 사실과 다르면 고쳐야 합니다.
